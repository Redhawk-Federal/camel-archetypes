# README #

These are Maven archetypes that generate Camel/SpringBoot applications. A README pertaining to each one can be found in their respective folders. Quick links for commands to run them:
- [OpenAPI archetype](https://github.com/Redhawk-Federal/camel-archetypes/blob/main/camel-openapi-archetype/README.md#how-do-i-run-the-archetype)
- [Scheduled archetype](https://github.com/Redhawk-Federal/camel-archetypes/tree/main/camel-scheduled-archetype#how-do-i-run-the-archetype)

The latest releases are published to [GitHub Packages](https://github.com/orgs/Redhawk-Federal/packages) under Redhawk-Federal. Reading them requires a GitHub token with the `read:packages` scope; see the setup steps in the [OpenAPI archetype README](https://github.com/Redhawk-Federal/camel-archetypes/blob/main/camel-openapi-archetype/README.md#how-do-i-get-set-up).

If making changes to one archetype and the changes are applicable to the others, please make the changes in both. A data comparison tool can be used to accomplish this more easily.
